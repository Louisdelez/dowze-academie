# Utilisation

Le premier onglet contient la navigation principale : accueil, planning, cours, évaluations, tâches et notes. Les onglets de notes restent distincts ; le bouton `+` sert à créer une nouvelle note dans un nouvel onglet.

Le panneau IA se déploie depuis la poignée latérale droite. Le compagnon se trouve dans la barre supérieure rétractable ; ses ressources font partie de l’application.

Les notes, dessins, pièces jointes et états de synchronisation sont présents dans les sources réunies ; les fonctions de la refonte encore en qualification sont identifiées dans `work-in-progress/`. Ne pas les déduire du seul numéro de version de ses fichiers préparatoires.

Sur mobile et tablette, ouvrir `https://academie.dowze.ch/app/` et utiliser la fonction d’installation du navigateur. L’accès au service et la synchronisation requièrent une session valide. Les données locales non synchronisées doivent être préservées avant nettoyage du navigateur ou désinstallation.
