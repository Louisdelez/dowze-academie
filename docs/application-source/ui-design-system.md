# Dowze Académie — espace d’étude, 0.7.0

Objectif : reprendre un cours, écrire une note, dessiner une idée, planifier et constater une progression réelle. Ordinateur et téléphone partagent leurs données via Dowze-01. Les 32 compagnons sont conservés, sans concurrencer le contenu.

Palette : encre20343b, secondaire52666c, papierffffff, bureauf3f6f6, ligne dce5e5, action176b62, action forte10534d, surface activee7f3f0. Typographie système ; corps14px, formulaire15/16px mobile, titre25–32px, métadonnées12px. Espacement8/12/16/24/32, rayons8/12/16 selon hiérarchie. Mouvement de contrôle140ms, reduced-motion et forced-colors conservés.

Architecture : navigation pédagogique, bibliothèque de notes accessible directement, dessins hors évaluations ; onglets documentaires dans le bureau ; panneau de services facultatif. Réglages indexés par compte/synchronisation, services, sauvegardes, confidentialité.

CSS : styles.css historique, ui-system.css garanties transversales, workspace-redesign.css direction commune, learning-redesign.css quatre parcours pédagogiques. PWA utilise ses propres styles compatibles avec les composants partagés.

Contrats : vide n’est pas zéro, moyenne n’est pas validation institutionnelle, sauvegarde affichée seulement après réception, cours à poursuivre déterminé par achèvement réel, brouillon dessin écrit avant envoi différé, aucun échange interne/service technique ajouté aux écrans.

Recette : vide/long texte/chargement/échec réseau, souris et clavier, fenêtres étroites et zoom, dessin puis navigation immédiate, conflit sync et changement de profil, focus onglets/dialogues, mise à jour réelle. SSR et vérification types ne constituent pas une preuve de recette native.
