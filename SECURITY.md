# Signalement de sécurité

Ne pas publier de secret, donnée utilisateur ou fichier de session dans une issue publique. Décrire le composant et les étapes de reproduction avec des données synthétiques. Les exemples d’infrastructure ne contiennent pas les paramètres privés de production. Voir `docs/CONFIDENTIALITE.md` pour les frontières de données et `docs/DEPLOIEMENT.md` pour les contrôles avant livraison.
